# 数据来源与选择记录

核实日期：2026-11-04。

## 选定数据

- 名称：Retailrocket recommender system dataset，原发布页列出 Roman Zykov。
- 原发布页：https://www.kaggle.com/datasets/retailrocket/ecommerce-dataset
- 原发布页的可索引详情：https://www.kaggle.com/retailrocket/ecommerce-dataset/home
- 官方版本 2 的事件文件接口：https://www.kaggle.com/api/v1/datasets/download/retailrocket/ecommerce-dataset/events.csv?datasetVersionNumber=2
- GitHub 检索入口与对照案例：https://github.com/jacobmackey01/product-funnel-activation-sql
- GitHub 数据目录说明：https://github.com/caserec/Datasets-for-Recommender-Systems/tree/master/Processed%20Datasets/RetailrocketEcommerce

这里需要区分：通过 GitHub 找到并核实分析案例和数据出处，完整原始数据下载自发布者的 Kaggle 页面，不把 GitHub 上的第三方镜像当作原发布者。没有复制运行上述项目的远程代码。本项目的下载、审计脚本单独编写。

原发布说明：真实电商网站匿名化事件，约 4.5 个月，2,756,101 条事件、1,407,580 位访客。包括 2,664,312 条 view、69,332 条 addtocart、22,457 条 transaction。最终以本地原始审计为准；清洗前后行数必须分别报告。

## 字段

| 原字段 | 含义 | 处理要求 |
|---|---|---|
| timestamp | 毫秒 Unix 时间戳 | 转 UTC；保留原值；不要误按秒解析 |
| visitorid | 匿名访客标识 | 访客不等于注册用户或跨设备自然人 |
| event | view / addtocart / transaction | 原样保留，映射含义写进字典 |
| itemid | 商品标识 | 商品购买路径按访客与商品共同关联 |
| transactionid | 成交事件中的交易标识 | 浏览/加购为空是合理情况，不做全表 dropna |

没有可直接使用的搜索词、营销渠道、设备、注册日期、真实价格、利润、退款和实验分流。不能据此声称分析广告 ROI、GMV、实际新客或 A/B 实验效果。交易事件行数不等于订单数：同一交易可能包含多个商品。

## 三个候选及取舍

| 候选 | 可取之处 | 取舍 |
|---|---|---|
| RetailRocket 原始 events.csv | 完整事件、访客、商品、毫秒时间，体量适中 | 主数据；先做事件级分析，不依赖额外大表 |
| GitHub caserec 的 Retailrocket 加工版 | 文件很小，易下载 | 说明中删除低活跃用户及商品并拆行为文件，不适合估计原始总体漏斗；不选 |
| REES46 行为数据 | 有 session、价格等，部分版本还含移出购物车 | 可后续换题材；本项目先用一份已核实的数据完成闭环，不同时下载多个数据集 |

REES46 发布者：https://rees46.com/en/datasets ，原始目录：https://data.rees46.com/ 。这里仅记录筛选，不把未经同等许可和文件校验的数据混入主项目。
